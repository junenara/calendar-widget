개인정보처리방침

시행일: 2026년 11월 25일

Calendar Widget(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 앱이 동작하는 데 꼭 필요한 정보만 사용합니다.

1. 앱이 요청하는 Google 권한

권한(범위)사용 목적
openidGoogle 계정으로 로그인하기 위해 사용합니다.
userinfo.email현재 로그인한 계정의 이메일 주소를 앱 화면에 표시하기 위해 사용합니다.
drive.appdata일정·할 일·메모 데이터를 사용자 Google Drive의 앱 전용 숨김 폴더에 저장하고 불러와 여러 기기 간에 동기화하기 위해 사용합니다.

2. 수집하지 않는 정보

  • 앱은 사용자 Google Drive의 다른 파일과 폴더에 접근할 수 없으며, 접근하지 않습니다.
  • 개발자는 별도의 서버를 운영하지 않으며, 사용자의 일정이나 개인정보를 개발자에게 전송하거나 수집하지 않습니다.
  • 광고, 분석, 추적 도구를 사용하지 않습니다.

3. 데이터 저장 위치

  • 앱 데이터는 사용자 본인의 Google Drive 앱 전용 폴더(appDataFolder)와 사용자 PC에만 저장됩니다.
  • 로그인 토큰은 사용자 PC에만 저장되며, 로그아웃하면 삭제됩니다.

4. 제3자 제공

앱은 사용자의 정보를 판매하거나 제3자에게 제공하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 준수합니다.

6. 데이터 삭제 및 권한 철회

  • 앱에서 로그아웃하면 PC에 저장된 로그인 정보가 삭제됩니다.
  • Google 계정의 서드파티 연결 관리에서 언제든지 앱의 접근 권한을 철회할 수 있습니다.
  • Google Drive 설정의 "앱 관리"에서 Calendar Widget의 숨김 앱 데이터를 삭제할 수 있습니다.
